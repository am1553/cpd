# CPD Log

Ongoing record of continuing professional development, mapped loosely against
[BCS/SFIA](https://www.bcs.org/articles-opinion-and-research/continuing-professional-development/)
skill areas. Entries added as they happen, not reconstructed after the fact.

## How to log an entry

| Field      | What goes here                                                                           |
| ---------- | ---------------------------------------------------------------------------------------- |
| Date       | When it happened                                                                         |
| Activity   | What you did, in a few words                                                             |
| Type       | Course / Reading / Conference / Mentoring / Technical decision / Talk or writing / Other |
| Time       | Rough hours spent                                                                        |
| Reflection | What changed — a skill gained, a decision improved, a gap noticed                        |
| Evidence   | Link/reference if there is one (repo, cert, PR, article)                                 |
